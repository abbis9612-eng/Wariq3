# الترسانة الوطنية (I-135، I-139)

18 صورة من `docs/art/grok-v6-flagship.md`. الملف يسمّي 18 صورة، والطلب قال 19؛ ما انضافت صورة زيادة.

نفس هوية العائلات: رأس رمح، خط أخضر مضيء، تمويه رمل وزيتون، شعار ذهبي (هلال يحضن رأس رمح). السفن والغواصة والزوارق رمادي ويا شريط رمل-زيتون.

صورة كبيرة لكل سلاح، ومن فوق للدبابة وفرط الصوت والمقاتلة والقاذفة والحاملة والمدمرة. المقاس الفعلي 1280×720. التركيب على كلاين، ونظام الترسانة باللعبة باقي عليه. ما تنعرض على المالك.
