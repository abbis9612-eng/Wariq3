# العالم 3D (WM11، I-065، D-033)

خريطة العالم كلها 3D بنفس الشكل المرسوم بثيمين (فاتح وغامق) مال «الحرب من فوق»، والحرب نفسها (`src/sim2.ts`، البذرة 3) بمجسمات 3D حقيقية.

- **شوفه:** https://claude.ai/artifact/8yoHiqbP9uFudDUA3QjNZR
- **النسخة 2D محفوظة ومجمّدة:** `../../archive/topdown-wm10.html` ورابطها Lx75CQEoksrNFSajMzuNTZ.
- **صور:** `preview.png` (العملية)، `preview_front.png` (الجبهة كاملة).

## الأرض: خمس مستويات تفاصيل (`tools/world.py` ← `terrain/`)
| المستوى | يغطي | الدقة |
|---|---|---|
| `w` | العالم كله (ميركاتور) | ~10 كم/بكسل، ارتفاع 512² |
| `me` | الشرق الأوسط | ~1.2 كم |
| `fr` | حدود العراق–إيران كلها (WM14.3) | ~0.15–0.23 كم |
| `th` | الجبهة (نفس حدود WM8) | ~130 م |
| `cl` | ساحة المعركة: البصرة ← شلامجة ← خرمشهر | ~19 م |

- **الطبقات:** الأدق تنحفر لها فتحة بالأخشن، و«تنورة» تسد الشقوق.
- **الرسم:** شيدر (`terr`) يرسم الخريطة ويضيف حبيبات تبين من قريب بس، وضباب لما تميل الكاميرا.
- **الجبال:** تتضخم حسب البعد (`exagOf`): ×1.3 من قريب، لحد ×22 من الفضاء.
- **المصادر:**
  - Natural Earth: الحدود والأنهار والبحيرات وأسماء الدول والمدن بالعربي.
  - AWS Terrain Tiles: الارتفاعات.
  - Sentinel-2 cloudless 2016 (EOX، CC BY 4.0): الخضرة والماء.

## الكاميرا (`src/cam.ts`)
- **الحالة:** هدف + بعد + اتجاه + ميلان، وتبدي من فوق.
- **الإصبع:** إصبع واحد يسحب. إصبعين: قرصة للتكبير، تدوير للف، وسحب سوا لفوق/تحت للميلان.
- **الماوس:** العجلة تكبّر، والزر اليمين أو Ctrl يلف ويميّل.
- **الدقة بالعالم الكبير:** كل شي ينرسم نسبةً لـ«مرساة» هي هدف الكاميرا، فالدقة عالية من الفضاء لحد الدبابة.

## الوحدات (`src/units.ts`)
- **المجسمات:** glTF مخففة (`tools/models.mjs`، وقبلها `tools/bl_decimate.py` للثقيلة).
- **الخبز:** كل مجسم ينخبز لشبكة وحدة: قدّامه +z، وطوله الحقيقي (`MODELS`).
- **الدبابات:** أبرامز وT-72 برجها منفصل يلف حول محوره (نفس حدود المسرح).
- **S-400:** يبقى بهيكله حتى حركة «Raise» تشتغل حسب المحاكاة.
- **الطيارات:** `orient(hd, gam, bank)` تعطي نفس الميلان والأنف مال المحاكاة.
- **الحجم:** حقيقي من قريب، ومن بعيد حد أدنى 16 بكسل (حجم ١/٢/٣).
- **الظل:** ظل الطيارة على الأرض.

## المؤثرات (`src/fx.ts`)
- **دخان وانفجار:** صور Unity Labs (CC0).
- **توهج:** بالإضافة.
- **ذيول دخان:** شريط يواجه الكاميرا، يتمدد مع الريح ويخفت.
- **آثار جنازير:** شريط مسطح على الأرض.
- **الأحجام:** تتحسب لكل كاميرا.

## اللقطة القريبة
كاميرا 3D ثانية (`pipCam`) تصوّر الإطلاق من الجنب بنافذة صغيرة، وتكبر بالضغط.

## تشغيل وفحص
```
npm install && npm run dev          # http://localhost:5173/
npm run test:sim                    # 10 فحوصات القصة + 9 فحوصات الفيزياء
python3 tools/world.py <ne> <cache> # يولّد terrain/ و labels/ (يحتاج ملفات Natural Earth geojson)
```
- **أدوات الفحص:**
  - `window.seek(t)` يقفز لوقت معين.
  - `window.camSet({D, tilt, head})` يحط الكاميرا.
  - `window.freeze()` يوقف الرسم.
  - `?auto&lite` يشغّل تلقائي وبدون نعومة.
- **البناء للنشر:** `npx vite build` (ملف JS واحد)، ثم `dist/artifact.html`.

## أكبر، أسرع، أقوى (WM12، I-067، D-034)

### الحجم
- **الحد الأدنى:** 44 بكسل للأرض و55 للجو.
- **الأحجام:** 4 (`SIZES`).
- **بعد لقطات المخرج:** `ZOOMS` (قريب/وسط/بعيد).
- **المؤثرات:** تكبر بـ `F.k`.

### الصواريخ (`models/m_*.gltf.json`)
- **المصدر:** Sketchfab (CC BY، شوف `models/CREDITS.md`).
- **مستخرجة من مجسمات أكبر:** 5V55 من منصة S-400 (`tools/bl_extract.py`)، وPAC-2 من منصة باتريوت (`tools/bl_extract_box.py`).
- **الاتجاه تلقائي:** أطول محور يصير +z، والرأس هو الطرف الأنحف.

### السرعة
- `GAME = 3`، والتبطيء ≤ 2.2 ث حقيقية (`rt0` بكل لقطة).

### الصوت
- **مركّب بـ WebAudio:**
  - `thump`: ضربة واطية 95→32 هرتز + طقة + خفض لحظي.
  - `updateEngines`: 4 محركات طيارات (ضوضاء بفلتر + دوبلر)، و2 دبابات (منشار 30–50 هرتز).
- **مركز الصوت:** هدف الكاميرا.

### قوة الضربة
- `impact`: اهتزاز (trauma²) + ومضة (`#flash`).
- `hitStop`: 70–130 ملي ثانية.
