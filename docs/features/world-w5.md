# «العالم» W5 — مسرح الحرب (I-103، D-049)

**الفكرة:** حروب اللاعب البرية بالتفصيل مثل «الحرب الكبرى»، وحروب باقي العالم مختصرة (ميزان قوة بـ `wsim.js`).

**الملفات:** `prototypes/world/theater.js` · `prototypes/world/gwsim.js` (نسخة من `prototypes/grandwar/sim.js` — عدّل الأصل وانسخ) · فحص `node tests/theater.test.mjs` و`node tests/world.test.mjs`.

## شلون ينبني المسرح
1. **المناطق:** كل مناطق الطرفين لحد 3 جيران من خط التماس (بأقصى حد 160 منطقة). الحرب بلا تماس بري (مثل أمريكا وإيران) تبقى مختصرة.
2. **الخلايا:** شبكة سداسية، المسافة بين المراكز 28–80 كم حتى يطلع ~900 خلية. كل خلية تاخذ منطقتها وأرضها (الغابة ← تلال، الأدغال ← أهوار، التندرا ← سهل، الثلج ← جبال).
3. **المدن = نقاط نصر:** مليون وفوك 6، 300 ألف 3، العاصمة +4.
4. **الخطوط المحصنة:** الجبهات القديمة (أوكرانيا) خط التماس وخليتين وراه «خطوط محصنة» (هجوم ×0.45، حركة ×0.55).
5. **الفرق من الجيش الحقيقي:**
   - المدافع على أرضه يرمي 90٪ من جيشه + نص الاحتياط، والمهاجم 50٪، والحليف 35٪، مضروب بحالة جيشه بالمحاكاة.
   - مدرعة = 240 دبابة، آلية = 220 مدرعة، مشاة = 12 ألف.
   - حد التلفون: أكبر طرف 70 فرقة، والطرفين ينضغطون بنفس النسبة.
6. **الجودة:** جيل الدبابات والطيارات (W4) والمسيّرات ترفع الصمود والهجوم.

## التشغيل
- كل يوم باللعبة = 24 ساعة قتال بالمسرح، وبعدها السيطرة ترجع للخريطة: المنطقة لمنو يمسك أغلب خلاياها.
- سير الحرب = تغيّر نقاط النصر؛ الاستسلام إذا الطرف خسر 70٪ من مدنه بالمسرح.
- **اللاعب:** وضع الجيش (هجوم / متوازن / دفاع بس / يدوي)، ويختار فرقة بالخريطة ويأمرها لأي خلية.
- **الذكاء:** محرك «الحرب الكبرى» + «التقدّم بالفراغ» للطرف الأقوى بوضوح (×1.3)، لأن الشبكة السداسية تخلي الجبهة مفتوحة أكثر.
