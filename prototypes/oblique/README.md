# المشهد المايل «2D مايل» (I-058، D-031) — بوابة WM7

تجربة صغيرة نحكم بيها على الشكل قبل ما نبني الحرب كلها بهالطريقة.

- **شوفها:** https://claude.ai/artifact/KEmGFJkmqMsxf9CT96iBza
- **صورة:** `preview.png`. الصف الأول: S-400 ينطرد ← يشتعل ← يميل ← الطيارة. الصف الثاني: ذو الفقار يطلع ← عموده ← PAC-3 ← الاعتراض.

## الفكرة
- **الكاميرا:** ثابتة الميلان 50°. الأرض تنضغط بالعمق (sin 50°)، والارتفاع يطلع لفوق بالشاشة (cos 50°)، فالطلوع العمودي يبين طلوع.
- **المجسمات:**
  - مخبوزة من نفس الزاوية بـ 16 اتجاه.
  - المنصات بحركاتها:
    - S-400 بحركة «Raise» الجاهزة من صانع المجسم (الأنابيب ترتفع عمودي).
    - ذو الفقار يرفع صاروخه.
- **الحجم والسرعة:** كل شي بحجمه وسرعته الحقيقية بالمتر والثانية. من بعيد الأشياء تصير رموز بحجم أدنى، ومسطرة تحت تبين المقياس.
- **المخرج («تابع»):** يختار لقطة لكل حدث ويبطّئ الوقت وقت الإطلاق والإصابة. الإصبع يسحب ويكبّر من 40 م لـ 300 كم.
