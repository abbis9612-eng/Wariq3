# تجربة 3D رقم 3 — معركة الهجوم (D-024)

**نفس معركة اللعبة الأساسية بالضبط** (لما تهاجم منطقة: 34 ثانية، استطلاع بالمسيّرات ← تمهيد مدفعي ← ضربات جوية ← ستار دخان ← تقدّم الدروع ← اقتحام المشاة)، بس مرسومة 3D بمجسمات حقيقية (I-047).

- **شوفها:** https://claude.ai/artifact/2CyLja8sxJV5eb5bL3KRat
- **شغّلها محلياً:** `npm install` ثم `npm run dev` (يحوّل المجسمات تلقائياً، ومنها مجسمات المسرح بأسماء `t_*`) وافتح `http://localhost:5173`
- **افحص إنها نفس الأصل:** `node tools/simtest.ts 150` — يشغّل كود `Battle` الأصلي من `index.html` داخل Node جنب `src/sim.ts` ويقارن المعدلات (لازم PASS)
- **صوّرها:** `node tools/shots.mjs <مجلد> win|lose|capital [desert|plain|hills|mount]` (vite على 5175)، `tools/close.mjs` لقطات قريبة للطيارات والهليكوبتر، `tools/view.mjs` اتجاه أي مجسم
- `?auto=1&r=lose&terr=hills` يبدأ مباشرة بنتيجة وأرض محددة.

## الفكرة
| الطبقة | الملف | ملاحظة |
|---|---|---|
| المعركة | `src/sim.ts` | نقل حرفي سطر بسطر لـ`Battle` (setup/step/kill/المراحل/البطاقة). الميدان 440×800 «بكسل» = متر. كل رسمة بالأصل صارت حدث `Fx` |
| الرسم | `src/main.ts` | أرض بنفس ألوان الأصل حسب نوع المنطقة + جبال بالأفق، الطريق نفس المنحنى، بيوت حقيقية بنفس أماكن الأصل وتنهدم، دبابات (أبرامز/T-72 ببرج يلف)، D-30، غراد، باتريوت/S-400، بيرقدار/شاهد، سوخوي-25/F-16، أباتشي، جنود متحركين (5 بكل مجموعة مثل نقاط الأصل)، انفجارات فليب بوك، حفر، حرائق، ستار دخان، أصوات حقيقية |
| الكاميرا | `shot()` بـ`main.ts` | «مخرج» يقطع بين اللقطات حسب المرحلة؛ لمسة = تحكم يدوي (سحب للف، إصبعين للتقريب)، زر 🎬 يرجّع المخرج |

## الأصول
المجسمات الجديدة بـ `models/` (مصادرها `models/CREDITS.md`). الباقي (دبابات، بيوت، جنود، قوام، أصوات) ينقرا **قراءة بس** من `../theater/` المجمّد (D-023).
