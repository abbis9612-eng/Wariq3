# المعركة الكلاسيكية (D-027، I-051)

**نفس معركة الهجوم بالأصل** (`index.html` → `Battle`): الساحة كلها بشاشة وحدة، وحدات مكبّرة، نفس الكثافة والانفجارات والأصوات والنتيجة —
بس الأشكال صارت **صور المجسمات الحقيقية** بإطار لون الطرف، وفوق انفجارات الأصل انفجار ودخان ونار مصوّرة، وفوق أصواته أصوات حقيقية.
المدة ~2.5 د (جدول الأصل × K=4.5 بموجات أكثر)، سرعات ×1–×8.

- **شوفها:** https://claude.ai/artifact/2K4CRwvNJ6kjQev9YBwHxj
- **شغّلها:** `npm install` ثم `npx vite`؛ `?auto=1&r=lose&terr=hills`
- **فحص المطابقة مع الأصل:** `node tools/simtest.ts 120` (يشغّل كود الأصل جنبها؛ الخسائر والتقدّم لازم يطابقون — بأقل من ~100 معركة ممكن فرق صدفة بالمعدلات)
- **صور:** `node tools/shots.mjs <مجلد> win|lose|capital [أرض]` (vite على 5179)

| الملف | الدور |
|---|---|
| `src/sim.ts` | منطق الأصل المنقول (من `battle3d`) × K: المراحل والخسائر والطلعات × K، الرمي بنفس معدلات الأصل (التمهيد ×2)، الحركة بقفزات (3 ث بسرعة الأصل لكل دورة 3K) |
| `src/main.ts` | `draw()` الأصل بصور حقيقية (`../battle2d/sprites`)، `explode()`/`puff()` الأصل + فليب بوك، `snd()` الأصل + تسجيلات، الحفر تبهت ببطء، تقريب اختياري بالإصبع |
