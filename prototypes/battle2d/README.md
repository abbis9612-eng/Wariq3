# تجربة رقم 4 — معركة الهجوم 2D الواقعية (I-049، D-026)

معركة الهجوم من فوق (مثل الأصل)، بس كل شي **صورة مخبوزة من المجسم الحقيقي**، وقتال حقيقي **~8–10 دقايق** بسرعات ×1 ×2 ×4 ×6 ×8.
النتيجة (فوز/خسارة وخسائر الطرفين) من **حساب اللعبة** (قوة كل دولة: عتاد × أجيال، تدريب، أرض، تكتيك…) والمعركة تمثّلها.

- **شوفها:** https://claude.ai/artifact/R8pnGHi8Sc5x2hR1tzfLe3
- **شغّلها محلياً:** `npm install` ثم `npx vite` وافتح الصفحة. `?auto=1&r=lose&terr=hills&tac=siege` يبدأ مباشرة.
- **افحص المعركة:** `node tools/simtest.ts 30` — كل حالة تخلص بوقتها والخسائر = ميزانية الحساب (لازم PASS)
- **صوّرها:** `node tools/shots.mjs <مجلد> win|lose|capital [أرض] [تكتيك]` (vite على 5177)
- **أعد خبز الصور:** `node tools/sprites.mjs` (vite على 5177) — يقرا مجسمات `../theater` و`../battle3d` (مجمّدين) ويكتب `sprites/*.png` + `manifest.json`

## كيف تشتغل
| الطبقة | الملف | ملاحظة |
|---|---|---|
| المعركة | `src/sim.ts` | مراحل الأصل ممدودة: مسيّرات تكشف ← مدفعية وراجمات على المكشوف ← طلعات جوية ودفاع جوي يسقط ← دخان ← دروع بقفزات (مجموعتين) ← ناقلات تنزّل مشاة ← اقتحام بيت بيت ← تطهير/انسحاب. كل طلقة لها رامي وهدف ومسار |
| منظّم الخسائر | `allowed()` + `mayKill()` | عدد القتلى النهائي لكل طرف = نفس معادلات الأصل من `la/ld/win`، والضربة تقتل بس إذا الطرف تحت منحناه الزمني |
| التكتيك | `create()` | حصار = تمهيد أطول؛ التفاف = الدبابات تلف من الشرق؛ مباشر = عادي |
| الرسم | `src/main.ts` | Canvas من فوق: أرض بألوان الأصل + تفاصيل مخبوزة، حفر وآثار جنازير تبقى، ظلال حسب الارتفاع، برج يلف، ارتداد، انفجارات فليب بوك، دخان، نار، بيوت تنهدم وعلم على المسيطر عليه، جنود فرادى ينبطحون ويرمون |
| الكاميرا | `director()` | مخرج يقطع بين الأحداث حسب المرحلة؛ لمسة = يدوي (سحب، إصبعين للتقريب)، 🎬 يرجّعه |
