# الحرب على الخريطة (I-055، D-030)

شهر هجوم واحد يتعرض حي على خريطة الدول نفسها اللي باللعبة. المرحلة الأولى «شكل بس»: النتيجة من نفس حساب الحرب، والمشهد يرسمها.

- **شوفها:** https://claude.ai/artifact/6HGueBuM8pecXSRJcSd4Dq
- **صورة:** `preview.png` (نجاح، من ث 2 لحد بطاقة النهاية)

## شنو بيها
- خريطة الدول من بيانات اللعبة (`MAPD`، نفس الإسقاط) مقصوصة لمنطقة العراق–إيران: `tools/extract.mjs` ← `src/mapdata.json`.
- `src/geo.ts`: مدن، أنهار، مطارات، دفاع جوي بمداه، قواعد صواريخ، الحدود، هدف الهجوم. الأماكن تقريبية من معلومات عامة [ASSUMPTION].
- `src/main.ts`: المشهد كله:
  - طيارات تقلع بالمدرج، تلف بحد أقصى للدوران، تضرب وترجع.
  - الدفاع الجوي يرمي على اللي يدخل مداه، والطيارة تناور وترمي مشاعل.
  - معترضات العدو بصواريخ جو-جو، باليستي بقوس وظل، وباتريوت يعترضه.
  - مدفعية، ورتل دروع يتقدم، وخط جبهة ومنطقة مأخوذة.
- **مطابقة الحساب:**
  - دبابات تنضرب = نفس معادلات الأصل: `fa = clamp(la×4.5)` و `fd` حسب الفوز.
  - الطيارات اللي تسقط عليها سقف من نفس النسب.
  - نسبة إصابة الدفاع الجوي من `la` و `ld`.
- الصور والأصوات مأخوذة (قراءة بس) من `../battle-classic/sprites|sounds` و `../theater/textures|sounds`؛ المصادر بـ `ASSETS.md` هناك.

## تشغيل
```
npm ci
npm run dev                         # http://localhost:5173/?auto&r=win|lose
node tools/shots.mjs win 2,8,16     # صور لحظات (السيرفر على 5181)
npm run build                       # dist/ ← artifact.html للنشر
```

## بعدين (مراحل 2–4 من D-030)
- الربط باللعبة: يطلع بعد «هاجم» قبل بطاقة النتيجة، لأي دولتين (مطارات ودفاع جوي لكل دولة).
- مرحلة القواعد الحقيقية: ضرب المطار يقلل طلعات العدو بالشهر الجاي، ويحتاج حقل حالة جديد + ترقية الحفظ.
