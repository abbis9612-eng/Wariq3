# «العالم» على التلفون (GW9)

> الحالة: ✅ PWA مفحوص (بدون نت، تحديث، حفظ احتياطي، زر الرجوع، قابل للتثبيت)؛ APK أندرويد بـ GitHub Actions — **ما انبنى هنا** (ماكو Android SDK بالبيئة)، أول تشغيل للـworkflow يأكده.

## الملفات
| الملف | شنو |
|---|---|
| `tools/app/build.mjs` | يبني `app/` (مو محفوظ بالـgit): `index.html` + كل سكربت تناديه الصفحة + الصور والأصوات من «الحرب الكبرى» + الأيقونات + `sw.js` بقائمة كل الملفات ونسخة (commit + بصمة المحتوى) |
| `tools/app/sw.tpl.js` | الـservice worker: يخزّن الكل وقت التثبيت؛ كاش أول؛ الصفحة بدون نت ترجع لـ`index.html`؛ النسخة الجديدة **تنتظر** لحد ما اللاعب يضغط «حدّث هسه» (`skip`)، والكاش القديم ينمسح |
| `prototypes/world/manifest.webmanifest` | الاسم، عربي RTL، عمودي، standalone، ألوان اللعبة، أيقونات 192/512 + maskable |
| `tools/app/icon.cjs` ← `prototypes/world/icons/` | الأيقونة (كرة أرضية ذهبية و«٣») |
| `mobile/` | Capacitor 8 (`com.wariq.world`، `webDir: ../app`)؛ `tools/app/android-icons.cjs` ← `mobile/res/` |
| `.github/workflows/world-app.yml` | بكل push يمس اللعبة: يبني `app/`، ينشره على GitHub Pages، ويبني `wariq-world.apk` (Artifacts) |

## بالصفحة (`prototypes/world/index.html`)
- **الحفظ الآمن:** قبل كل كتابة النسخة القديمة تروح لـ`wariq.world.v1.bak`؛ نتأكد إن اللي انكتب يتقرا؛ إذا الأصل خربان نقرا الاحتياط. أول حفظ يطلب `navigator.storage.persist()`.
- **تصدير/استيراد الحفظ كملف** (شاشة البداية و🏛 دولتي ← الاقتصاد): مشاركة الملف بالتلفون أو تنزيله؛ الاستيراد يفحص الملف ويرقّيه (`S.load`). هذا الحفظ الوحيد اللي يبقى إذا انمسح التطبيق أو آيفون مسح التخزين.
- **زر الرجوع:** يسكّر اللي فوك بالترتيب (الخطة، تحديد الفرق، اللوح، البطاقة)؛ بالخريطة يحتاج ضغطتين بثانيتين للخروج، ويحفظ قبل.
- **التحديث:** شريط «🆕 أكو تحديث للعبة — حدّث هسه» (يحفظ قبل ما يبدّل).
- الـservice worker ينسجل بس إذا `version.txt` موجود (يعني بنسخة التطبيق)، فالـartifact وفتح الملف مباشرة ما يتأثرون.

## اللي انفحص هنا (Chromium بلا شاشة)
- Chrome: ماكو أخطاء تثبيت ولا أخطاء manifest.
- بدون نت: إعادة تحميل، بداية لعبة، 70 يوم، صور المعركة، إعادة تحميل، «كمّل» يرجع نفس اليوم.
- الحفظ الخربان ← يرجع للاحتياط.
- التحديث: نسخة جديدة ← الشريط يطلع ← «حدّث» ← تتحمل الجديدة، الكاش القديم ينمسح، والحفظ باقي.
- زر الرجوع يسكّر اللوح.
- Capacitor: `npm ci` ← `cap add android` ← `cap sync` ← الأيقونات والاتجاه العمودي (نفس خطوات الـworkflow) نجحت هنا؛ **Gradle ما انفحص**.

## اللي يحتاج المالك
1. **مرة وحدة:** GitHub ← Settings ← Pages ← Source: **GitHub Actions** (حتى ينشر الرابط). ممكن Pages يقبل بس الفرع الافتراضي؛ إذا رفض، ينشر بعد الدمج.
2. **APK:** GitHub ← Actions ← world-app ← آخر run ← Artifacts ← `wariq-world-apk` ← فك الضغط ← ثبّت (يحتاج «السماح من مصادر غير معروفة»). نسخة debug (مو للمتجر).
3. **التلفون:** تثبيت الـPWA من المتصفح (أضف للشاشة الرئيسية)، اللعب بدون نت، 15 دقيقة للحرارة، وزر الرجوع.
4. **آيفون:** يحتاج ماك و Xcode وحساب مطوّر؛ لحد ذاك الـPWA من Safari + تصدير الحفظ.
