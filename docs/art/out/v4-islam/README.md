# السلاح الوطني — تمويه صحراوي على أخضر (I-133)

32 صورة. كل وحدة بلقطتين: يسار من فوق، يمين من الجنب، المقدمة لليمين. الخلفية بيضاء.

الطلاء مطبوع: زيتوني وبقع رمل كبيرة، مو رمادي ومو لون فوق أسود. كل جيل أقوى شكلاً من اللي قبله (دبابة، مدرعة، مدفعية، مسيّرة، صاروخ، دفاع جوي، طيارة، سفينة).

المقاس 1280×720. التركيب على كلاين. ما تنعرض على المالك.
