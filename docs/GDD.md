## الملخص

تختار دولة حقيقية من 45 دولة وتحكمها شهر بشهر من تشرين الأول 2026 لحد سنة نهاية تختارها (2030/2036/2040/2050). تدير الاقتصاد والموارد والجيش والدبلوماسية والسلاح النووي، بنقاط قرار محدودة كل شهر، بعالم متوتر فيه حرب روسيا وأوكرانيا قائمة. تخسر بانقلاب أو ثورة أو إفلاس أو سقوط العاصمة. تفوز إذا صرت الأول بالقوة ومسيطر على ربع ناتج العالم سنة كاملة، أو تُقيَّم بسنة النهاية.

| | |
|---|---|
| النوع | استراتيجية كبرى (Grand Strategy) بالأدوار، شهر = دور |
| الجمهور | لاعب عربي يحب السياسة والجيوش، جلسات قصيرة على التلفون |
| المنصة والتحكم | ويب موبايل (عمودي، لمس)، يشتغل على الكمبيوتر أيضاً |
| الجلسة | الشهر < دقيقة؛ الحملة عشرات الأشهر |
| التقنية | HTML + CSS + JavaScript بملف واحد، Canvas للخريطة والمعركة، Web Audio للصوت |
| اللغة | عربي، لهجة عراقية بالتقارير والأزرار |

## الأعمدة (Pillars)

1. **رهانات حقيقية بعالم حقيقي.** دول وأرقام وجغرافيا حقيقية تقريبياً.
2. **كل شهر قرار.** نقاط القرار قليلة عمداً (3/4/5 حسب الصعوبة).
3. **السبب ← النتيجة واضح.** كل رقم يتحرك لازم يكون له تفسير.
4. **القوة لها ثمن.** التوسع يرفع الخوف والتحالفات ضدك والتعب والدين وكلفة الاحتلال.
5. **جلسة قصيرة، حملة طويلة.**

## الحلقة الأساسية

```
اقرأ التقرير وحل القضايا العاجلة ← وزّع نقاط القرار (ميزانية، دبلوماسية، تسليح، بحث، حرب)
← الشهر التالي ← العالم يتحرك (اقتصاد، ذكاء اصطناعي، حروب، أحداث) ← تقرير جديد
```

## شروط الخسارة (من الكود)

- الجيش (فئة) < 20 لمدة 3 أشهر ← انقلاب.
- الاستقرار < 15 لمدة 3 أشهر ← ثورة.
- الدين > 3 أضعاف الناتج، أو > ضعفين لمدة 6 أشهر ← إفلاس.
- سقوط العاصمة.

## شروط الفوز (من الكود)

- الأول بمؤشر القوة + حصة ≥ max(25٪، حصتك الأولى + 8٪) من ناتج العالم لمدة 12 شهر.
- أو سنة النهاية: تقييم حسب الترتيب ونمو القوة («قوة عظمى» ... «هزيمة»). ⚠️ حالياً كل تقييم غير «هزيمة» = فوز (راجع R3).

## المسرد (المصطلحات الثابتة)

| المصطلح | المعنى |
|---|---|
| نقاط القرار | عدد الأفعال المسموحة بالشهر |
| مؤشر الخوف | خوف العالم من توسعك (0-100)؛ ≥60 تحالف ضدك، ≥85 حرب محتملة |
| القوة القتالية | مجموع (عدد × وزن الفئة × معامل الجيل) × النوعية |
| النوعية | التدريب × الصيانة × الإمداد × المعنويات |
| تعب الشعب | يرتفع بالحرب، يضغط على الشارع والاستقرار |
