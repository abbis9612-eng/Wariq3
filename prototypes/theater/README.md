# تجربة 3D رقم 2 — مسرح عمليات بغداد

هجوم على بغداد من الجو والأرض، تشوفه من فوق بزاوية مايلة، مع اسم على كل شي (I-010، I-011).

**النسخة 2** (I-012…I-021، [التصميم](../../docs/features/war-theater/design.md)): S-400 بإطلاق بارد ضد صواريخ إسكندر الباليستية، إطلاق واضح لكل سلاح، دوشكا طلقة طلقة، كاميرا إصابة بحركة بطيئة، دمار (برج يطير، بنايات تنهدم)، بطاقة الثمن، رتل ينتشر ويتقدم بقفزات، أبرامز ورا سواتر، 4 أوامر، خريطة مصغّرة وأسهم حافة، أضواء انفجارات وظلال قريبة، وزر جودة ✦.

- **شوفها:** https://claude.ai/artifact/C9Sj8mD44WNBCGgmE5CFdN
- **شغّلها محلياً:** `npm install` ثم `npm run dev` (يحوّل المجسمات تلقائياً) وافتح `http://localhost:5173`
- **افحص المعركة بالحساب:** `npm run test:sim` أو `node tools/simtest.ts <seed>` (لازم تخلص `over=true`)
- **صوّرها:** `node tools/autoshots.mjs "http://localhost:5174/index.html?auto=1&q=low" <مجلد>` (الكاميرا التلقائية) و`tools/closeups.mjs` (تتبع وحدات)
- `?auto=1` يبدأ بدون ضغطة، `?q=low` جودة منخفضة.

## شنو فيها
| الطبقة | التفاصيل |
|---|---|
| الخريطة | دجلة متعرج، مدينة (~6 آلاف بناية بنداء رسم واحد)، نخيل، طرق، جسور، مطار، مصفى الدورة |
| الجو | 8 مسيّرات شاهد-136 بموجتين، 3 كروز Kh-101؛ باتريوت يطلق معترضين PAC-2 بتوجيه تناسبي؛ دوشكات وبيكبات تضرب المسيّرات |
| الأرض | رتل معادي (4 T-72B3 + بيكبات) على طريق أبو غريب، راجمتين غراد (رشقتين)، خط 3 أبرامز، دوشكات بسيطرة، مدفعين D-30 |
| العرض | من بعيد مجموعات («خط الأبرامز ×3»)، من قريب اسم كل وحدة؛ علامات أرض ملونة؛ ضغطة على أي اسم = الكاميرا تلاحقه |
| المخرج التلقائي 🎬 | يروح لإطلاقات الباتريوت والاعتراضات والإصابات؛ يتوقف لما تلمس الشاشة |
| النتيجة | عدادات حيّة + شريط أحداث (اضغطه ويوديك لمكان الحدث) + بطاقة نتيجة بالنهاية |

## الملفات
| الملف | الدور |
|---|---|
| `src/sim.ts` | المعركة كلها بدون رسم (وحدات، أسلحة، مديات، إصابات، جدول الهجمات) — تتفحص بـ Node |
| `src/main.ts` | الرسم والكاميرا والمخرج التلقائي والأسماء والمؤثرات والصوت والأوامر |

**الإضاءة (مهم):** خامات Standard تقصّ الضوء عند 1، فالشمس خفيفة (0.75) والتعريض عالي (1.75)، والمجسمات PBR تاخذ `directIntensity=2.5`. إذا رفعت الشمس، الأرض والبنايات تبيض وأضواء الانفجارات ما تبين.
| `models/*.glb` + `models/CREDITS.md` | المجسمات المخففة ومصادرها (CC BY 4.0) |
| `tools/prep.mjs` | تخفيف مجسم: شيل أجزاء، تبسيط، قوام WebP |
