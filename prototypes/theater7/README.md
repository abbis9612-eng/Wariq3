# مسرح العمليات v7 (I-170، D-066)

**الأساس الجديد لمشهد المعركة**: نسخة من «مسرح العمليات» v6 المجمّد (`../theater`، D-023) نضيف عليها أحسن ما بالنماذج الثانية خطوة خطوة.
المجسمات والقوام والأصوات القديمة **تنقرا من `../theater` بدون نسخ** (المجلد هذاك ما ينعدل)، وأصوات المالك من `../grandwar/sounds/bz_*.mp3`.

- **شغّلها:** `npm ci` ثم `npm run dev` (يحوّل مجسمات `../theater/models/*.glb` لـ`models/*.gltf.json` هنا، أول مرة بس) — `?auto=1&q=low`
- **ابنها للنشر:** `npm run build` ← `dist/`
- **افحص المعركة بالحساب:** `node tools/simtest.ts <seed>` (لازم تخلص بنتيجة)
